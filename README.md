# Peng Liu Personal Website

This repository now includes a GitHub Pages-ready personal website generated from your CV content.

## Files

- `index.html`: main page
- `assets/style.css`: styles
- `assets/main.js`: interaction and language toggle
- `photo.jpg`: profile photo
- `PengLiu_cv.pdf` / `cv-cn.pdf`: CV downloads
- `DEPLOY_GITHUB_PAGES.md`: deployment guide in Chinese

## Local preview

Open `index.html` directly in your browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000`
